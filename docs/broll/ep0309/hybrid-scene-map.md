## Prompt Pack (Batch 1)

### C001 — Hook Title (6s)
**Prompt (video/animation, 16:9):**
System Glow infographic title card on deep navy background, soft white Korean text, amber highlight. Main title: “좋은 아침이 좋은 하루를 만든다”. Secondary small text: “직장인 아침 루틴”. Minimal sunrise icon, subtle progress ring at right. Clean grid layout, subtitle-safe lower 20% empty. Motion: slow fade-in (0.4s), gentle glow pulse on one keyword (0.8s), ambient drift. No photoreal faces. Crisp vector/SVG style.

### C002 — Problem Question Punch (5s)
**Prompt:**
Minimal question card with bold Korean quote: “그래서 아침에 뭘 해야, 진짜 하루가 달라지는데?” Amber underline sweep animation under “뭘 해야”. Add small ⚠️ badge. Background: dark charcoal/navy, subtle noise. Motion: card slides in from left (0.35s), underline draws (0.6s), hold with tiny pulse.

### C003 — Chaos Montage (6s)
**Prompt:**
Infographic montage of morning chaos: alarm clock icon, phone notification chips (메일/메신저), calendar popups, all as flat vector UI cards. Add “CHAOS METER” bar rising then stabilizing. Keep center clean for subtitles. Motion: 3 cards pop-in staggered (80ms offsets), bar grows (1.2s), then calm.

### C004 — Not About Morning Person (6s)
**Prompt:**
Bold stamp graphic “아침형 인간 얘기 아님” with a red-ish muted stamp effect (not neon), then fade to a clean frame labeled “구조”. Dim background elements to 40% then bring focus box to 100%. Motion: stamp-in (0.2s) + settle, focus frame draws.

### C005 — Tease Core 3 (7s)
**Prompt:**
Three-step framework teaser: 3 vertical cards labeled 1) 폰/알림 차단 2) 할 일 3개 3) 10분 착수. Each card has ✅ icon and a thin connector line. Motion: reveal card 1→2→3 in sync (0.35s each), connector line draws, amber highlight sweep across “코어 3개”.
